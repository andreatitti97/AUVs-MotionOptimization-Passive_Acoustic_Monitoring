# AUVs-MotionOptimization-Passive_Acoustic_Monitoring

This repository contains a motion-optimization framework for bearing-only tracking with a team of autonomous underwater vehicles (AUVs) navigating in formation.

## Overview

The project addresses passive acoustic source localization and tracking using bearing-only measurements. The main idea is to optimize the formation path of the AUV team with respect to the target motion, enabling coordinated motion control and cooperative target tracking in underwater scenarios.

## Research context

This work is related to adaptive planning and coordinated navigation for multi-agent underwater systems, with emphasis on autonomous tracking and formation control.
